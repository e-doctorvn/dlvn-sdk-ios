Chuyển EdoctorDlvnSdk từ CocoaPods sang Swift Package Manager

Từ bản 2.0.0, SDK iOS của eDoctor chỉ phát hành qua Swift Package Manager (SPM). Tài liệu này hướng dẫn app DLVN chuyển sang SPM ngay ở bản 1.4.0, không phải đổi code.

1.4.0Bản cuối cùng trên CocoaPods
2.0.0Chỉ còn SPM
iOS 13.0+Không đổi
0 dòngCode cần sửa trong app

Vì sao cần chuyển

  • CocoaPods trunk sắp chuyển sang chỉ đọc (theo lịch là khoảng 02/12/2026); sau mốc đó không phát hành được bản mới qua CocoaPods. Bản 1.4.0 là bản cuối trên kênh này.
  • Thư viện gọi video SendBirdCalls đã ngừng phát hành trên CocoaPods từ 1.11.0. Các bản sửa lỗi và nâng cấp Sendbird sau này chỉ có qua SPM.
  • Trên SPM, SDK đã dùng SendbirdChatSDK mới hơn bản có trên CocoaPods (4.39.11 trở lên so với 4.39.10).

Đề nghị: chuyển sang SPM ở bản 1.4.0 rồi phát hành app như bình thường. Bản 2.0.0 giữ nguyên API; eDoctor sẽ phát hành sau khi DLVN xác nhận app đã chuyển xong.

Yêu cầu

  • Xcode 26 trở lên. Sendbird Chat 4.39.x cần Xcode 26.
  • App có deployment target iOS 13 hoặc 14 phải build bằng Xcode 26.x. Xcode 27 chỉ hỗ trợ deployment target từ iOS 15.
  • Repo github.com/e-doctorvn/dlvn-sdk-ios hiện để công khai, nên không cần access token để tải package.

Các bước chuyển

  1. Gỡ SDK khỏi Podfile

    Xoá dòng khai báo SDK. Nếu app có khai báo trực tiếp các pod Sendbird thì xoá luôn, vì sẽ thêm lại qua SPM ở bước 3.

    ruby
    # Xoá các dòng này khỏi Podfile
pod 'EdoctorDlvnSdk', '~> 1.3'
pod 'SendBirdCalls'      # nếu có
pod 'SendbirdChatSDK'    # nếu có

    Chạy pod install nếu app còn dùng pod khác. Nếu không còn pod nào, chạy pod deintegrate rồi mở file .xcodeproj thay cho .xcworkspace.

  2. Thêm SDK bằng SPM

    1. Trong Xcode chọn File → Add Package Dependencies…
    2. Dán URL https://github.com/e-doctorvn/dlvn-sdk-ios.
    3. Chọn Dependency Rule Up to Next Major Version từ 1.4.0.
    4. Chọn product EdoctorDlvnSdk cho target app, rồi bấm Add Package.

    Nếu app quản lý dependency bằng Package.swift:

    swift
    .package(url: "https://github.com/e-doctorvn/dlvn-sdk-ios.git", from: "1.4.0")

// trong target của app
.product(name: "EdoctorDlvnSdk", package: "dlvn-sdk-ios")

  3. Đưa toàn bộ Sendbird sang SPM

    SDK tự kéo Sendbird về qua SPM. Không để Sendbird nằm đồng thời ở Pods và SPM: app sẽ có hai bản thư viện, dẫn tới lỗi trùng symbol khi build hoặc crash khi chạy.

    Nếu code của app có dùng Sendbird trực tiếp, thêm Sendbird qua SPM với phiên bản tương thích như bảng dưới. Cách đơn giản nhất là import module mà SDK đã kéo về, không cần khai báo thêm.

    Thư việnPhiên bản SDK yêu cầuBản SPM đang resolve
    SendbirdChatSDK4.39.11 – < 5.04.39.14
    SendbirdAuthSDK (đi kèm Chat)theo Chat1.2.2
    SendBirdCallsđúng 1.10.221.10.22
    SendBirdWebRTC (đi kèm Calls)theo Calls1.8.1

    Bản SDK 1.4.0 được kiểm thử với Chat 4.39.11 và Auth 1.2.0. Khi tải mới, SPM sẽ lấy Chat 4.39.14 và Auth 1.2.2, nên cần test kỹ luồng chat và gọi video (xem checklist).

  4. Giữ nguyên code tích hợp

    API không đổi. Các lệnh import vẫn như cũ:

    swift
    import EdoctorDlvnSdk
    objective-c
    @import EdoctorDlvnSdk;

    Nếu app có gán biến isCocoapod, có thể xoá. Biến này không còn tác dụng, và sẽ báo cảnh báo deprecated từ bản 2.0.0.

  5. Kiểm tra icon CallKit

    Màn hình cuộc gọi của hệ thống lấy ảnh icLogoSymbolInverse từ asset catalog của app. Nếu app đang có ảnh này thì không cần làm gì. Nếu chưa có, thêm một ảnh template (đơn sắc, nền trong suốt) với đúng tên này vào Assets.xcassets.

  6. Cấu hình CI

    Trên máy build, chọn Xcode 26.x nếu app có deployment target dưới iOS 15. Nên resolve package trước khi build:

    bash
    export DEVELOPER_DIR=/Applications/Xcode-26.2.0.app/Contents/Developer
xcodebuild -resolvePackageDependencies -project MyApp.xcodeproj
xcodebuild build -project MyApp.xcodeproj -scheme MyApp -destination 'generic/platform=iOS'

    Commit file Package.resolved của app (nằm trong *.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/) để mọi máy build cùng một phiên bản dependency.

Checklist kiểm thử

Đánh dấu khi đã kiểm tra trên thiết bị thật. Trang chỉ ghi nhớ các dấu tích trên trình duyệt của bạn.

Lỗi thường gặp

Lỗi duplicate symbol, hoặc log "Class … is implemented in both"

Sendbird đang nằm ở cả Pods và SPM. Xoá hết pod Sendbird khỏi Podfile, chạy pod install, sau đó chọn Product → Clean Build Folder.

"The iOS Simulator deployment target … is set to 13.0, but the range of supported deployment target versions is 15.0 to …"

Đang build bằng Xcode 27. Chuyển sang Xcode 26.x, hoặc dùng DEVELOPER_DIR như ở bước 6.

Thiếu ảnh ở widget hoặc màn hình gọi

Bản SDK cũ hơn 1.4.0 có lỗi không tải được ảnh khi tích hợp bằng SPM. Kiểm tra trong Package Dependencies để chắc đang dùng 1.4.0 trở lên.

"Missing package product 'EdoctorDlvnSdk'" hoặc package không resolve được

Chọn File → Packages → Reset Package Caches, rồi File → Packages → Resolve Package Versions. Trên CI, chạy xcodebuild -resolvePackageDependencies trước bước build.

Lên 2.0.0 nhưng Xcode vẫn giữ 1.x

Rule "Up to Next Major" đặt từ 1.4.0 sẽ không tự lên 2.0.0. Khi eDoctor phát hành 2.0.0, đổi rule thành from: "2.0.0".
